failures.jsonl / review.jsonl 处理失败与待人工复核清单

明确的使用边界

  • 这是半自动工具，需人工复核，不保证完整性。非空字段与“结构完整”不等于科研内容准确。
  • 固定20篇已用Python解析器处理；新增论文在网页使用PDF.js规则基线，两个引擎的结果可能不同。
  • 公式保留PDF文字候选，暂不重建LaTeX；数值保留原句及单位，不自动比较不同实验条件。
  • 多栏、特殊符号、图表和未知章节仍可能影响内容。扫描件无OCR；没有接入真实NER或LLM。
  • 向量检索为词项哈希基线，不能理解所有同义词。关系图只表示正文提及，证据助手只返回引用。
  • 网页每批最多50篇、单篇100MiB、暂存PDF合计300MiB；本地批处理最多5,000条任务。真实语料评测仅20篇。
  • PDF下载请按各篇许可使用；不绕过付费墙。arXiv预印本不一定经过同行评审。
  • 当前是仅所有者可访问的工作区。原文摘录与复核结果可保存到工作区；本地PDF本身不会上传。

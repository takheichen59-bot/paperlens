# 图解中文报告

默认中文报告用浅蓝色卡片呈现有出处的论文要点，用浅黄色卡片呈现生活比喻，用浅灰色卡片呈现理解示意和阅读边界。每篇按“研究与方法”“图解与比喻”“发现、结论与核对”分开阅读；没有图解或比喻的旧记录仍可导出，不补造解释。

## 内容与来源

生活比喻存放在已有 `reading_card.source_review` 的可选 `reading_aids` 中，独立声明 `paperlens-reading-aids-1` 与 `assistant_explanation`。每个比喻必须有标题、解释、适用边界和对应原句；不能以论文作者名义写入结果字段。

配图仅允许五种可回查的矢量概念示意：颗粒与表面、制备顺序、颗粒聚集、传感器功能、薄层界面。必须标记 `not_original_figure: true`，附中文图注、范围提醒和来源句。它们不是论文原图、显微照片、测量曲线或可复现实验方案；系统不生成虚构实验数据图。

中文导读原有的论文指纹、论文标识、原题名、版本和完整来源句绑定继续生效。没有出处、没有比喻边界、冒充原图或使用未知图形类型时，拒绝导出。旧记录不因缺少 `reading_aids` 而失效。

## 排版

`reading-layout.js` 单独负责中文卡片布局，`report-illustrations.js` 绘制概念示意；原英文摘录版保留。正文11.5pt、分区标签、统一留白、独立的可点击来源行和目录书签保持一致。分区过长会换页，单个分区超出安全页高会明确报错，不截断科学说明。中文换行处理句末标点和括号，避免右标点孤立到行首，拉丁单词保持完整。

网页同步展示带边界的生活比喻；Excel的“中文导读”表末尾增加生活比喻、边界和配图说明，原列与原始数据保留。

真实五篇中的中文比喻由助手整理，并非通用自动比喻模型或独立科研金标准。原自动字段、来源和用户复核不变。没有新增模型服务、费用或外部论文上传。

# 项目功能与内容

更新：2026-11-17。版本0.3.0。

## 1. 产品用途

PaperLens 面向需要阅读大量学术论文的研究者。核心工作不是聊天，而是将真实文献的“发现、获取、解析、记录、证据、复核、导出”串起来。当前材料科学是已积累真实语料的领域；新检索与结构化模型同时覆盖可信AI、形式化验证、约束推理、优化与科学AI。

工作流：

1. 输入主题、DOI或作者，按年份、期刊、引用量和开放状态筛选。
2. 多来源返回统一元数据，并按DOI优先去重；目标20/100/500/1000/5000是任务目标，不会用虚构论文补齐。
3. 在合法范围获取全文，或上传已有授权PDF。记录许可、字节数、时间、获取方式和SHA-256。
4. 按页面、段落、章节、图表、公式候选解析，保留来源映射。
5. 使用规则基线，或在配置真实模型后按专门任务提取科研内容。
6. 点击证据回到原文页码与片段；人工记录复核意见。
7. 比较所选论文，导出结构化JSONL、CSV、Excel，或带许可清单的PDF包。

## 2. 三条代码路径

### M01–M20 契约与流水线

`contracts` 定义严格Pydantic数据对象、抽象接口、状态和安全错误；`storage` 提供SQLite状态与迁移；`fetchers`、`parsers`、`extractors`、`pipeline`、`exports` 和 `paper_platform` 提供基础批处理与CLI。

已验收接口继续冻结。该路径的 `success` 主要表示证据结构和字段完整性，不代表科学内容准确。NER/LLM基线仍是模拟适配器。

### research 材料论文工具

`src/research/` 扩展为四核心字段：材料、方法、结论、主要发现，并保留算法/公式/数值等规则候选。支持人工修订、比较、引用检索、关系图、本地恢复和版本化导出。

已有20篇真实材料论文的历史结果：材料18/20、方法10/20、结论15/20、发现17/20非空。这里“非空”不是precision/recall或专家可用率。956条片段中，历史诊断记录了414条unknown-section片段，不能据此宣称全字段无泄漏。

本轮修复包括跨平台锁、失败条目隔离、记录历史、源变更失效和导出快照。网站Worker增加不可变记录版本与条件指针发布，减少并发覆盖。Worker修复经过本地逻辑测试，尚未在真实R2环境重新发布验证。

### science_platform 新研究工作区

独立FastAPI应用与独立SQLite数据库，不替换旧接口。实现公共来源适配器、安全获取、解析与提取接口、持久任务、版本证据、复核API及网站。

它有实际可调用的后端，但真实模型提取尚未执行，因此不应把这条路径列为已验证的科研情报产品。

## 3. 检索与获取

来源包括 Crossref、OpenAlex、Semantic Scholar、arXiv、Springer、Elsevier。后两者需要授权，元数据API授权不自动等于全文授权。

统一字段包括 DOI、标题、作者、年份、venue、引用量、摘要、原文链接、OA信息、全文候选、参考文献与来源事实。去重保留来源，不把不同非空DOI仅凭相似标题强行合并。

有持续化检索任务、分页游标、限流和有限重试。公共数据并不保证作者、venue或参考文献齐全；跨来源字段分歧保留待审查。

通用全文链接使用公共IP校验及IP固定连接；官方来源的代理兼容模式只允许固定官方主机，并逐跳检查。两个安全模式不等价。当前环境中通用IP固定公网下载失败，官方白名单模式真实下载成功，不能把后者作为前者已验证的证据。

## 4. 解析与提取

PyMuPDF保留页码与几何信息；Tesseract支持扫描件OCR；JATS XML保留元素路径，不编造PDF页码。GROBID/Docling提供独立适配器和结构对齐逻辑，但尚无真实双解析器验收。

公式只在源解析器实际提供LaTeX时保留LaTeX，否则标记不确定。图注、参考文献、致谢等不进入正常提取候选。多页表格与算法框的真实覆盖尚未完整评测。

深度Schema包含：

- 研究问题、动机、贡献；
- 算法名称、类别、创新归属、输入输出、组件、步骤、伪代码；
- 目标函数、约束、优化策略、复杂度、假设、失效条件；
- 数学模型、方法、实验设计、数据集、对照、指标、参数、硬件；
- 实际数值、单位与条件；
- 作者陈述、实验观察及AI推断的局限分区；
- 结论、未来工作、缺失字段和冲突。

12类专项提取任务可对章节分段处理，有限重试，严格校验JSON和证据。并没有实现可靠的AI假设生成；AI推断局限字段保留为空。跨章节协调目前只覆盖有限的算法创新归属冲突，不是完整科学矛盾检测。

## 5. 证据与研究情报

每条证据关联paper_id、文档哈希、segment、页码、章节、原句、字符偏移、模型与版本。片段存在性通过，不等于科学真实性或解释正确性通过。

文件改变或被替换时，旧提取/复核进入STALE并作为历史保留。人工复核采用版本检查，避免静默覆盖他人更新。

算法浏览器只读结构化算法；比较限定2–10篇，保留Not Reported，不自动对不同数据集数值排名。BM25是真实词项检索；可配置真实嵌入进行候选重排，但尚不是完整的语义候选召回。证据不足时问答拒答；无模型时只展示来源片段，不生成科研答案。

关系图来源于实际元数据/结构化记录，支持论文、作者、venue、引用、算法、目标、约束、实验与结果证据等已有关系。所需的全部方法—数据集—局限关系尚未齐备。

## 6. 页面

新版网站包含：总览、文献检索、文献库、论文详情、算法浏览、比较、研究空白、关系图、证据问答、任务监控和设置。

论文详情为原文/结构化内容/证据检查三栏自适应布局。支持PDF页码跳转和原始段落高亮；不是PDF画布上的精确区域高亮。上传使用实际字节进度，随后进行格式验证。

这些页面已经接API。本轮已执行Chromium12项工程流程及5项真实来源冒烟，截图见[浏览器报告](qa/workflow-20261117/REPORT.md)。跨浏览器、真机和生产部署仍未验收。

## 7. 仓库组成

| 目录 | 内容 |
|---|---|
| `src/contracts`, `src/storage` | 冻结基础接口和原状态库 |
| `src/fetchers`, `parsers`, `extractors`, `pipeline`, `exports` | M01–M20获取/解析/抽取/导出 |
| `src/research` | 规则科研汇总、本地库、审阅、批处理 |
| `src/science_platform` | 新API、任务、独立模型和状态库、解析/模型客户端 |
| `src/science_platform/web` | 新版本地网站HTML/CSS/JavaScript |
| `website` | 旧版托管Worker网站源码、固定公开元数据/测试fixture |
| `acceptance`, `tests/master`, `samples` | 独立验收、30项新单元/集成测试、合成样本 |
| `scripts`, `launch` | 复验、获取、审计、恢复、启动与历史打包脚本 |
| `docs`, `logs/github` | 当前说明、历史诊断和真实测试日志 |

不包含真实论文PDF、个人数据库、密钥、私有复核记录或运行备份。当前没有对原创代码作开放许可证授权。

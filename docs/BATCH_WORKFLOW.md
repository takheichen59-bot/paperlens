# 一键批量获取与自动提取

首页输入研究关键词或arXiv ID，选择5、10或20篇，点击 **一键爬取并生成 PDF / Excel**。无需先逐篇勾选。Crossref仍提供普通元数据检索；一键全文流程使用arXiv公开全文。

系统依次查询真实来源、核对来源记录的许可、获取原PDF、以PDF.js读取全文、执行通用逐句提取、校验证据，并生成PDF、Excel、JSONL及证据CSV。完成后可自动下载含原论文的ZIP，也可在批次页单独下载文件。

- 处理期间保持标签页开启，可切换站内页面。关闭/刷新后从已保存检查点继续，不能视为后台定时任务。
- 每批最多20篇、每篇最多25MiB。超限、限流、扫描件缺少OCR、损坏或加密PDF保留具体原因；完成项不因其他条目失败而重做。
- 原PDF和提取记录逐篇存入现有私有工作区；生成文件先暂存，齐备后发布为同一批次版本。失败格式不会静默冒充成功，其余可用文件仍可下载。
- 仅重试失败项；解析失败时重新获取原文，保留旧失败文件哈希与历史，不无限复用损坏缓存。已完成提取检查点保留。
- 相同PDF在批次内去重；失败、重复与未取得目标名额分别计数。来源返回少于目标时按实际数量处理，不补入示例论文。
- arXiv查询限流/故障时，普通关键词可使用OpenAlex真实元数据后备，只接受具有arXiv原文位置的条目，界面明确标注来源。arXiv专用查询语法不静默转译。全文仍从arXiv取得。
- OpenAlex的许可类型没有精确版本信息时不编造4.0/3.0版本；元数据来源与许可来源保留在记录里。

报告固定框架见 [REPORT_FRAMEWORK.md](REPORT_FRAMEWORK.md)。自动提取版本为 `browser-scientific-rules-v1.5`，布局为 `pdfjs-layout-v1.1`，独立阅读层为 `reading-evidence-browser-v2.1`。新版本直接从来源句生成方法、发现与结论字段；原基线单独保存在legacy_record，旧服务器记录保留历史。来源切片一致不代表归属或科学内容已被专家确认。

存储使用独立的paperlens-batch-1检查点、不可变版本和batches/前缀，不修改冻结contracts、旧storage或SQL结构。现有私有站点的受众不变。不存在付费模型、外部论文上传、外部翻译或模型生成结果。

本批文件：`report.pdf`、`research.xlsx`、`research.jsonl`、`reading-evidence.csv`。ZIP另含实际保存的原PDF及`BATCH-MANIFEST.json`，其中记录真实失败原因、来源与许可。不要把处理报告当成原始论文。

Python阅读兼容校验增加主动制备/测量动词，同时升级scientific-evidence-v1.4和reading-evidence-v1.1，使旧缓存不会冒充新规则结果；旧版本仍可读取，未静默重写。两种解析实现继续记录各自版本，不声称与浏览器输出等价。

# 中文阅读与报告结构

本轮把面向读者的中文说明与自动提取结果分开。默认 PDF 和阅读页使用中文；化学式、单位和论文编号按原样保留。英文原句在证据检查器、Excel 和 JSONL 中回查。

## 三层职责

1. **原文与提取层**：`pdf-reader-research.js` 读取版面，`reading-rules.js` 提取句子。保留原始块、字符位置、旧基线及版本，不用中文改写英文原句。
2. **中文导读层**：`reading-chinese.js` 把已有 `reading_card.source_review` 转成独立的中文阅读计划。新增中文说明绑定论文指纹、论文标识、原题名、解析和阅读版本，以及每条引用的完整原句。对应原句变了，拒绝继续套用这份导读。历史中文导读保持可读，但明确说明没有按新版要求重新核对。
3. **展示层**：网页、PDF 和 Excel 使用同一中文阅读计划。PDF 默认中文；`language: 'source'` 仍可输出英文原句版。Excel在原表之后新增“中文导读”，保留原表顺序和原字段。

## 报告怎么读

每篇按“这篇文章想弄清什么 → 主要研究什么 → 作者怎么做 → 大致步骤 → 最值得注意的发现 → 作者的结论 → 还要核对什么”展开。正文使用易读中文，页码可回到原文。详细的块编号、偏移和英文证据移到配套文件。

没有中文导读时，只提供能够确定的对象、技术线索和“待补充”说明，不把英文段落放进中文正文，也不编造中文科研结论。综述不套用实验步骤模板。

## 来源和执行边界

当前没有配置翻译模型。本轮5篇中文导读由助手对照真实原文整理，标记为 `assistant_source_review`、`language: zh-CN`、`human_review_status: unreviewed`、`independent_gold: false`，不是通用自动翻译、用户人工复核或独立科研金标准。导读和全文输出只保存在私有工作区。公开工程夹具均为合成数据。

沿用已有 `research-1` 和可选 `source_review`，没有修改冻结的 contracts、旧 storage 或 SQL。原自动字段、旧版警告及用户复核各自保留。新布局为 `pdfjs-layout-v1.2`，提取器为 `browser-scientific-rules-v1.7`，阅读层为 `reading-evidence-browser-v2.2`；旧版本仍可读取，只有明确重处理的论文生成新版本。

## 同时修复的提取问题

- 竖排 arXiv 页边标记保留在原始块里，但不参与横向分栏和正文提取，避免连接左右两栏。
- 首页面的机构地址不再拼进研究句，前缀排除记录可回查。
- 化学式补充识别核对元素符号；声子标签 LO1/TO1 不当材料，疑似带参考文献号的缩写不提升为研究对象。
- 新版已识别方法或结论时，不再显示旧基线的“未找到”警告；旧警告仍存于 `legacy_warnings`。

这些规则减少已观察到的误报，不代表所有论文的版面、对象和科研归属都已正确。普通多词检索偏宽、引用与本文结果的识别、通用中文语义生成仍需要继续完善。

# 检索故障恢复

2026-11-19：针对正式站“2D”检索两次HTTP502进行修复。原arXiv元数据来源发生瞬时故障，原后备OpenAlex当时返回HTTP503并明确暂停匿名检索。原代码没有可用的第三来源、按词保存的真实检索缓存，检索为空的失败批次也缺少重试按钮。

- arXiv仍是首选；短暂HTTP错误按官方请求间隔有限重试，较长Retry-After直接转后备，不密集撞源。
- 独立后备为DataCite登记的arXiv元数据，限定已核实的arxiv.content客户端、10.48550/arXiv DOI及相符的官方原文ID。另保留OpenAlex的arXiv位置后备。不需要付费模型或新密钥。全文仍只从arXiv获取。
- 每一来源有超时上限，保留状态/限流/超时诊断。HTTP200的HTML错误页或损坏Atom不当作“零结果成功”。
- 成功元数据写入独立discovery/v1缓存；检索词、提供方、条数精确匹配。15分钟内可复用，7天内旧结果仅在实时来源均失败后使用，界面显示历史结果及取得时间。不替换为固定样例，也不把旧结果标成实时更新。
- 检索失败且尚未取得论文的批次显示“重新检索本批”，保留同一检查点后继续。完成论文、原PDF和已发布文件不因来源故障清除。
- 来源和缓存状态在页面、批次、PDF、Excel及ZIP清单保留。界面脚本禁用长期缓存，降低更新后模块混用风险。

未建立付费或私有论文外部处理路径。精确arXiv版本及arXiv专用查询语法不静默改成宽泛关键词。缓存不是最新文献保证，实际来源仍可能发生持续故障；无匹配缓存时返回可重试错误，不能承诺外部网站永久可用。

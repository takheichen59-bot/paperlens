# 一次生成主题对比和逐篇阅读

首页输入主题和篇数，点“一键生成中文 PDF”。系统在同一页面检索开放论文、读取原文、提取并生成文件。完整 PDF 前半做本组主题对比，后半逐篇展开；另外保存独立的 `overview.pdf`、`papers.pdf` 和 Excel、JSONL、证据CSV。完整 PDF 在本地生成后立即尝试下载，不再等待全部文件上传或先下载含原文的大ZIP。浏览器限制自动下载时，原位提供下载按钮。

高级检索仍可单独查看元数据。来源故障、部分论文失败、缺少中文导读和页面中断分别显示，不把结构完成状态当作内容已核实。页面刷新后从版本化批次继续。生成期间仍需保持标签页打开，没有承诺后台常驻任务。

## 减少等待

- 字体按本次实际文字保留原字形ID、复合字形依赖、字宽、提示和排版表，不使用曾丢失中文轮廓的 fontkit 动态子集。整个过程在本机内存中完成，没有向外部翻译或字体服务上传论文。三个PDF共用一次字体读取和字形裁剪。
- 一次最多处理两篇，持久检查点串行写入，避免R2修订指针互相覆盖；同指纹并发任务等待同一处理结果并去重。暂停和失败重试保留已完成工作。
- 默认优先复用同论文ID、同标题、同解析/提取/阅读版本、已校验证据与已存PDF指纹的记录，原中文说明和复核不重写。复用不代表重新下载上游最新版；界面和PDF明确标记，可取消复用强制重新获取。检索依然使用实际来源，不用文献库替代搜索。
- 字体和提取规则在开始时提前读取；完成PDF后先交付，其他文件继续保存。

`pdf_ready_ms`记录本次运行到PDF准备好的耗时，`total_ms`包括持久化全部文件；本地生成基准与检索/下载总耗时分开记录，不把缓存命中速度宣传成首次下载速度。

## 证据和兼容

主题对比只把有来源的研究对象、方法、发现与结论并排放置；不把不同实验条件的数值直接排名，也不自动推出共同因果结论。中文说明使用现有严格来源绑定；缺少完整中文导读时写明缺项，保留原文题目与证据入口。当前没有配置通用语义翻译/综述模型，不能称为自动科研级综述。

已有R2批次仍用 `paperlens-batch-1`，旧四文件下载不变。新的可选 `report_profile: dual-pdf-v1`声明六文件展示方案；只有新生成/用户重新生成时才创建新文件代次，不在读取旧批次时静默迁移。文件仍通过不可变哈希对象和条件指针一次发布。新增可选运行时间、复用和中文覆盖统计，仅属于网站批次记录。`research-1`、冻结 `src/contracts/`、旧SQLite接口与表结构均不变。

实际验证数量和耗时以本次PR及交付记录为准。合成浏览器测试不冒充生产检索，已有真实原文的复用不冒充新下载。

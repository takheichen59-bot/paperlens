# 自动研究报告框架

本框架用于新的浏览器自动批次，不套用五篇示例的助手中文导读。界面和报告使用相同的自动证据层；原论文语言保留，没有配置语义翻译或外部模型。

| 部分 | 固定展示内容 | 缺失或不适用时 |
| --- | --- | --- |
| 批量概览 | 检索词、实际来源、目标/返回/完成/失败/重复数量、论文导航 | 保留未完成与失败原因，不用示例补足数量 |
| 研究问题 | 摘要/引言中的研究目的完整句 | 标记未定位，不自行编写问题 |
| 研究对象 | 本文对象、组分变体、宿主/杂质、研究主题 | 背景提及和角色未确认的材料留在审计层 |
| 方法路线 | 计算、制备、测量、验证线索；具体技术词与原句 | 技术词只是可回查候选，不是深度算法分析 |
| 操作线索 | 方法语句按来源顺序排列，附页码 | 不把原文出现顺序当成完整、已验证实验流程 |
| 发现 / 论点 | 当前研究结果完整句；观点文章展示论点与方法挑战 | 不把未来计划或引用结果补作本文结果 |
| 作者结论 | 明确结论段或结语候选 | 不复制发现来制造独立结论 |
| 数值与条件 | 完整绑定的关键数值；分角色的未绑定候选及缺失提示 | 未知条件保持未知，不推断单位/比较基准 |
| 局限 | 作者明确局限原句 | 未识别不等于没有局限 |
| 证据与来源 | 原论文页码、可点击原文、块及Unicode字符区间、完整JSONL入口 | 字面来源存在不证明科学解释正确 |

PDF使用11pt正文、固定章节和单独结论/证据页，通常每篇2页；长内容明确保留在完整JSONL，不截断原句伪造摘要，不缩字号塞入页面。观点/综述候选不套用实验结果模板。PDF中包含可选择文字、书签和来源链接，可直接下载，无需浏览器打印。

Excel在原有审计表之外增加阅读卡片、关键数值及阅读证据映射；一键批次另外包含执行状态表。自动结果、历史基线、人工修订分开保存。没有独立领域专家金标准，不能据此宣称科研级生产准确率。

安装与使用

半自动工具，需人工复核，不保证完整性。第一阶段仅支持 arXiv。

① 安装 Python 工具

Python 3.11+。下载 wheel 后，在虚拟环境内安装：

python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install paper_extraction_contracts-0.1.2-py3-none-any.whl
下载 wheel ↓ 源码与验收 ↓

② 打开完整 Python 网页工作台

paperlens-web --online

自动打开 http://127.0.0.1:8765。使用同一界面检索、上传或处理选定论文；PDF 由本机 Python 流水线处理，状态与结果保存在 work/paperlens-web。不加 --online 可离线上传 PDF。

托管网站提供检索、回归数据浏览和浏览器快速预筛；它不在云端运行 PyMuPDF。浏览器预筛不是此页统计的 Python 结果。要使用已验收流水线，请运行上面的本地命令。

③ 批量处理与复验

paperlens run --manifest examples/demo_manifest.json --db work/demo/state.sqlite3 --workdir work/demo/cache --output work/demo/results
python scripts/verify_all.py
python scripts/verify_resume.py

默认 PDF 上限 100 MiB，可通过 CLI/TOML 覆盖。四份输出以版本目录和 CURRENT 原子发布；成组读取必须使用共享快照辅助函数。详见交付包 README。

使用边界与隐私

不覆盖所有论文来源；扫描 PDF 需要外部 OCR。词典与价态规则可能漏掉聚合物、非整数化学式与复杂配位结构，尚无独立人工金标准或 recall 评估。原文可能混入图表文字或半句，请逐条核验。

上传 PDF 在浏览器或本地 Python 服务处理，不上传托管站点。在线检索会向 arXiv 发送关键词；浏览器预筛需要从 CDN 加载 PDF.js。已保存文献仅保留在当前浏览器；共享设备请谨慎保存。
